# Getting Started with the IISD-ELA GitHub
&nbsp;&nbsp;&nbsp;To make uploading your project to the IISD-ELA GitHub as easy as possible, we strongly recommend using our **automated GitHub project submission system**. The submission system is extremely straightforward and requires no prior GitHub knowledge or interaction with GitHub itself. All you need to do is drop your project files and fill out a simple form, and the system creates your GitHub repository and ensures that it follows our organizational standards.  

&nbsp;&nbsp;&nbsp;This section will walk you through the submission process. For additional details about how the system works (entirely optional!), see [Appendix 2 - The IISD-ELA GitHub Project Submission System](appendices/appendix-2-auto-submission-system.md).  

&nbsp;&nbsp;&nbsp;If you're an experienced GitHub user who prefers to create repositories manually, you're welcome to continue doing so, but **please ensure that all new repositories follow our [repository guidelines](appendix-1-repo-creation.md)**. Even for experienced users, we encourage using the automated system, as it saves time and handles these requirements for you.

### Step 1 - Get Access to the IISD-ELA GitHub Organization
&nbsp;&nbsp;&nbsp;Before submitting a project, you must have a GitHub account that is a member of the IISD-ELA GitHub organization.

* **I don't have a GitHub account.**  
[Sign up for GitHub](https://github.com/signup), using your IISD-ELA email address if possible. Then, email the IISD-ELA data team to request access to the IISD-ELA GitHub organization.
* **I already have a GitHub account but I do not have access to our GitHub organization.**
Email the IISD-ELA data team to request access to the IISD-ELA GitHub organization.
* **I already have a GitHub account and am a member of our GitHub organization.**  
Skip this step.

To request access, contact the IISD-ELA data team at iyaktubay@iisd-ela.org or eladata@iisd-ela.org.

### Step 2 - Create your repository through our automated submission system
&nbsp;&nbsp;&nbsp;Once you have a GitHub account and are a member of our GitHub organization, you can submit your project using our GitHub project submission system:

1. Simply upload your project files to our designated [IISD-ELA GitHub Projects Dropbox](https://drive.google.com/drive/folders/1x922EzeZKErssw4pwZXoaOc-TPY5olu7?usp=drive_link) folder by following the instructions in the short [READMEFIRST](https://docs.google.com/document/d/1eCa5YFolbrqcge32kDppIOliPDPeAORpq9xa0qv4u8g/edit?usp=drive_link) file - **please read this file carefully**.
2. Our submission system runs automatically every night. Your repository will be created during the next overnight run after you submit your project, and you'll receive an email notification once it's ready. *If you need your repository created sooner, just contact me on Teams or via email (iyaktubay@iisd-ela.org), and I can run the system manually to get it set up right away.*

&nbsp;&nbsp;&nbsp;All staff with a `@iisd-ela.org` email address have been granted access to the [IISD-ELA GitHub Projects Dropbox](https://drive.google.com/drive/folders/1x922EzeZKErssw4pwZXoaOc-TPY5olu7?usp=drive_link) folder. If you do not have access, please contact the IISD-ELA data team at iyaktubay@iisd-ela.org or eladata@iisd-ela.org.

### Step 3 - Decide what to do next
&nbsp;&nbsp;&nbsp;Once your project has been uploaded to GitHub by our system, you have two options:

#### Option 1: Preserve your project
&nbsp;&nbsp;&nbsp;If your goal was to simply store your work for future reference, **you're done!** Your repository is now discoverable in the IISD-ELA GitHub organization by the teams you chose to grant access to during the submission process.  
&nbsp;&nbsp;&nbsp;*If you would like to generate a DOI for your repository to cite it in a publication, please refer to the [xyz](#xyz) section in this handbook for instructions.*

#### Option 2: Continue Developing Your Project
&nbsp;&nbsp;&nbsp;If you would like to update files, track changes, or collaborate with colleagues, you can work directly with your repository using the GitHub website or tools such as Visual Studio Code (VS Code) and RStudio. You can learn these skills at your own pace using the information and resources provided in the [GitHub Learning Resources](github-learning-resources/introduction.md) section in this handbook.
