# End of "Level 3: Collaboration - working with others"

&nbsp;&nbsp;&nbsp;After completing "Level 3 - Collaboration - working with others", you should know how to do the following using Git and GitHub:

* Create and manage branches to work on changes independently of the main project
* Create pull requests to propose changes to a repository
* Review, discuss, and approve changes made by collaborators
* Merge branches and pull requests into the main branch
* Identify and resolve merge conflicts
* Follow a consistent Git workflow to collaborate effectively with others.

**You've completed all three levels of the IISD-ELA GitHub training materials!** You should now have the skills needed to independently manage your projects and collaborate with other staff using Git and GitHub. Remember that you can always return to these tutorials whenever you need a refresher.
