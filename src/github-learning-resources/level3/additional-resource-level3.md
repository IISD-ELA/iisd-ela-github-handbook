# Additional Resource: Software Versioning and Quality Control
&nbsp;&nbsp;&nbsp;For larger or more complex software projects, teams may benefit from more structured practices for versioning, testing, and reviewing changes. While working on the IISD Prairie Watershed Analytics (PWA) project, the data team developed a detailed software versioning process covering these practices. This document is available in [Appendix 7 - Software Versioning & Quality Control Process at IISD-ELA](../../appendices/appendix-7-version-control-practices.md) as an ***optional reference*** for teams interested in adopting more rigorous software development practices.
