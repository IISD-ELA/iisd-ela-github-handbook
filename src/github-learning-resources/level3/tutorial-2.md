# Level 3 - Tutorial 2 - Creating and working with branches
&nbsp;&nbsp;&nbsp;In this tutorial, you will learn how to create branches, switch between them, and use them to develop changes independently.

### 1. Understanding branches
&nbsp;&nbsp;&nbsp;A branch is a separate line of development within a Git repository. By default, your repository will have a branch called `main`. When you create a new branch, you can make changes and commits without affecting `main` until you're ready to merge them.

### 2. Creating a branch
&nbsp;&nbsp;&nbsp;You can create branches directly through GitHub, RStudio, or VS Code.

#### Option A: GitHub website
1. Open your repository on GitHub.
2. Click the branch selector (usually displaying main) above the file list.
3. Enter a name for your new branch.
4. Select ***Create branch***,

#### Option B: RStudio

1. Open your local repository in RStudio.
2. Navigate to the ***Git*** tab.
3. Click ***New Branch***.
4. Enter a descriptive branch name and create the branch.
5. If available, select the option to sync with the remote repository.

#### Option C: VS Code
1. Open your local repository in VS Code.
2. Click the current branch name in the bottom-left status bar.
3. Select Create new branch.
4. Enter a descriptive branch name.
5. VS Code will create the branch and switch to it.  

&nbsp;&nbsp;&nbsp;When you're ready to upload your branch to GitHub, use **Publish Branch** in the Source Control panel.
