# GitHub Learning Resources for IISD-ELA Staff
&nbsp;&nbsp;&nbsp;You've created and uploaded your project to GitHub using [our submission system](appendices/appendix-2-auto-submission-system.md). Now, if you choose to continue developing your project, this section will guide you through different ways you can do that, starting with the simplest approach and gradually introducing more advanced tools and techniques.

---

&nbsp;&nbsp;&nbsp;As a reminder, not everyone or every project may need the same level of Git/GitHub complexity. You can choose to learn about the right workflow depending on your situation:  

| Situation | Recommended approach |
|---|---|
| Occasionally updating repository files | GitHub website ([Level 1](level-1.md)) |
| Actively developing a repository, with you as the sole contributor | Local Git workflow ([Level 2](level-2.md)) |
| Actively developing a repository, with multiple contributors | Branches and pull requests ([Level 3](level-3.md)) |
