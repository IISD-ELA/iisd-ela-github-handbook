# Additional Resource: Building and editing Markdown files
&nbsp;&nbsp;&nbsp;Markdown is a simple way to format text using basic symbols instead of a traditional word processor. As you've previously seen in the Level 1 tutorials, Markdown files (`.md`) are commonly used on GitHub to create `README.md` files, project documentation, instructions, protocols, and other written resources associated with your GitHub project.

&nbsp;&nbsp;&nbsp;If you'd like to learn how to build and edit Markdown files, see [Appendix 9 - Building and editing Markdown files](../../appendices/appendix-9-markdown.md). This resource covers basic Markdown syntax, creating and editing Markdown files on GitHub, using VS Code for more advanced editing, and links to additional tutorials and resources.
