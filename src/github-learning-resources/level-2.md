# Level 2:  Version Control - working independently
**Difficulty:** Intermediate (no prior Git experience required)  
**Tools required:** Git and a code editor (e.g., RStudio or VS Code)  

&nbsp;&nbsp;&nbsp;In [Level 1](level-1.md), you learned how to manage your IISD-ELA repository and make changes directly through the GitHub website. While this works well for occasional updates, you may prefer to work on your project directly from your computer, especially if you're regularly developing R or Python scripts, running analyses, making data visualizations, or working with multiple files.  

&nbsp;&nbsp;&nbsp;Here, you'll learn how to use Git to track changes to your files locally and synchronize your work with your repository on GitHub with tools such as RStudio or VS Code. You'll learn how to download ("clone") an existing repository, make and save changes, upload your updates to GitHub, and retrieve changes made by others.

&nbsp;&nbsp;&nbsp;We will focus on the graphical Git interfaces available in RStudio and VS Code, with occasional command-line examples where useful. So, **no command-line experience is required**. By the end of this level, you'll be able to independently develop and maintain your projects on your computer while keeping them connected to GitHub for version control.
