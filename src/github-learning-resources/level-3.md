# Level 3: Collaboration - working with others

**Difficulty:** Advanced (completion of Level 2 recommended)  
**Tools required:** Git, GitHub and a code editor (e.g., RStudio or VS Code)

&nbsp;&nbsp;&nbsp;In [Level 2](level-2.md), you learned how to use Git to independently develop and maintain projects on your computer while keeping them synchronized with GitHub. However, when multiple people are working on the same repository, additional tools and practices can help coordinate changes and avoid conflicts.

&nbsp;&nbsp;&nbsp;In this level, you'll learn how to **collaborate with others on GitHub** using branches, pull requests, code reviews, and other collaborative features. You'll learn how to work on changes without affecting the main version of a project, propose and review contributions, merge updates, and resolve conflicts when changes overlap.

&nbsp;&nbsp;&nbsp;As in Level 2, we'll focus primarily on the graphical interfaces available in GitHub, RStudio, and VS Code, so **no command-line experience is required**. By the end of this level, you'll be able to contribute to shared IISD-ELA projects and collaborate with colleagues while keeping your repositories organized and their version histories intact.
