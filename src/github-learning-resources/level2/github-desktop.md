### Alternative Tool: GitHub Desktop

&nbsp;&nbsp;&nbsp;The tutorials in this handbook so far only focused on **RStudio** and **VS Code** because these are the tools most commonly used by IISD-ELA staff. Both applications also have built-in Git interfaces, allowing you to manage version control directly within the same environment where you do your work.

&nbsp;&nbsp;&nbsp;However, you can also use [GitHub Desktop](https://desktop.github.com/), a more beginner-friendly application dedicated specifically to managing Git repositories. Unlike RStudio and VS Code, GitHub Desktop is not a code editor. Instead, it provides a simple graphical interface for tasks like cloning repositories, committing changes, and pushing or pulling updates. **You might prefer GitHub Desktop if you want a more beginner-friendly interface for Git.** Though, if you are already comfortable using VS Code or RStudio's Git interface, there's little reason to switch to GitHub desktop.
