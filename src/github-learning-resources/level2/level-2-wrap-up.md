# End of "Level 2: Version Control - working independently"

&nbsp;&nbsp;&nbsp;After completing "Level 2 - Version Control - working independently", you should know how to do the following using Git through RStudio or VS Code:

* Install and configure Git on your computer
* Clone an IISD-ELA GitHub repository to your computer
* Make changes to repository files locally
* Stage and commit changes to track your project's development
* Push commits to GitHub and pull changes to keep your local repository up to date
* View commit history, compare file versions, and undo changes
* Follow a consistent Git workflow to manage your projects independently.

**You can stop here if these skills meet your needs!** If you want to learn how to collaborate with others using branches, pull requests, and other GitHub features, continue to [Level 3](../level-3.md).
