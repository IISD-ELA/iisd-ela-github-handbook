# Level 1: GitHub Basics - working in your browser

**Difficulty:** Beginner  
**Tools required:** Web browser and your GitHub account  

&nbsp;&nbsp;&nbsp;In this section, we introduce the most basic features of GitHub that you can use through its website, without installing any software. **For most staff, the skills covered in this section may be all you need.** If you just want to preserve your work, occasionally update files, or keep track of changes without getting into more advanced GitHub features, you may  not need to go beyond this section.  

&nbsp;&nbsp;&nbsp;For example, you might want to maintain an SOP for processing water samples, occasionally update an R script used to make calculations, or keep a record of changes to a field sampling procedure. All of these can be done directly through the GitHub website without additional software.
