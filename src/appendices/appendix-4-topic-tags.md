# 1. Topic Tags
&nbsp;&nbsp;&nbsp;Topic tags help categorize repositories across the IISD-ELA GitHub so that staff and external users can easily discover related work. Below are our standardized topic tags, with a link to all repositories tagged with each topic. Each of our repositories have exactly one primary tag, and between one and two secondary topic tags.

**Primary Topic Tags**  

| Topic Tag (with Link) | Description |
|----------|-------------|
| [`chemistry`](https://github.com/search?q=topic%3Achemistry+org%3AIISD-ELA&type=Repositories) | Repositories related to chemistry work at IISD-ELA or associated organizations. |
| [`fish`](https://github.com/search?q=topic%3Afish+org%3AIISD-ELA&type=Repositories) | Repositories related to fish work at IISD-ELA or associated organizations. |
| [`general`](https://github.com/search?q=topic%3Ageneral+org%3AIISD-ELA&type=Repositories) | Repositories that do not correspond to a specific data type. Most data system related repositories fall into this category. |
| [`hydrolim`](https://github.com/search?q=topic%3Ahydrolim+org%3AIISD-ELA&type=Repositories) | Repositories related to meteorology, hydrology, or limnology work at IISD-ELA or associated organizations. |
| [`phytoplankton`](https://github.com/search?q=topic%3Aphytoplankton+org%3AIISD-ELA&type=Repositories) | Repositories related to phytoplankton work at IISD-ELA or associated organizations. |
| [`publication`](https://github.com/search?q=topic%3Apublication+org%3AIISD-ELA&type=Repositories) | Repositories related to IISD-ELA scientific publications. |
| [`water-program`](https://github.com/search?q=topic%3Awater-program+org%3AIISD-ELA&type=Repositories) | Repositories related to water projects carried out by IISD, IISD-ELA or associated organizations. |
| [`zooplankton`](https://github.com/IISD-ELA/zoop-data-processing) | Repositories related to zooplankton work at IISD-ELA or associated organizations. |


**Secondary Topic Tags**  

| Topic Tag (with Link) | Description |
|-----------|-------------|
| [`analysis`](https://github.com/search?q=topic%3Aanalysis+org%3AIISD-ELA&type=Repositories) | Repositories focused on statistical analysis, interpretation, scripts, notebooks, or analytical workflows that are not reusable data pipelines (e.g., trend analyses, exploratory analyses, modeling experiments). |
| [`backend`](https://github.com/search?q=topic%3Abackend+org%3AIISD-ELA&type=Repositories) | Server-side, APIs, or database logic for specific smaller projects or apps (e.g., repo backends for web applications such as dashboards). This is different from the `infra-tools` tag, which is reserved for broad-scale infrastructure repos mostly used by data admins. |
| [`data-repository`](https://github.com/search?q=topic%3Adata-repository+org%3AIISD-ELA&type=Repositories) | Repositories that primarily store data rather than code (e.g., hackathon data) |
| [`data-workflow`](https://github.com/search?q=topic%3Adata-workflow+org%3AIISD-ELA&type=Repositories) | Reproducible workflows or standardized scripts that transform raw data to processed data (e.g., automated QA/QC scripts, ETL pipelines). |
| [`documentation`](https://github.com/search?q=topic%3Adocumentation+org%3AIISD-ELA&type=Repositories) | Repositories like “info sheets,” SOPs, written guides. |
| [`github-admin`](https://github.com/search?q=topic%3Agithub-admin+org%3AIISD-ELA&type=Repositories) | Repositories related to the organization of the IISD-ELA GitHub account. |
| [`monitoring`](https://github.com/search?q=topic%3Amonitoring+org%3AIISD-ELA&type=Repositories) | Anything related to environmental monitoring programs (e.g., adaptive monitoring, climate change, contaminants etc.). |
| [`gis`](https://github.com/search?q=topic%3Agis+org%3AIISD-ELA&type=Repositories) | Anything that primarily involves geospatial work (e.g., bathymetry processing). |
| [`infra-tools`](https://github.com/search?q=topic%3Ainfra-tools+org%3AIISD-ELA&type=Repositories) | Infrastructure-as-code, devops, deployment, cloud provisioning (e.g., OpenTofu, Docker, AWS). Reserved for broadscale infrastructure repos mostly used by data admins. |
| [`modelling`](https://github.com/search?q=topic%3Amodelling+org%3AIISD-ELA&type=Repositories) | Repositories that create predictive models, machine learning, simulations etc. (e.g., ice-off model). |
| [`remote-sensing`](https://github.com/search?q=topic%3Aremote-sensing+org%3AIISD-ELA&type=Repositories) | Satellite, aerial, or telemetered retrievals. |
| [`visualization`](https://github.com/search?q=topic%3Avisualization+org%3AIISD-ELA&type=Repositories) | Repositories focused on dashboards, plots, figures, visualization tools, color palettes (e.g., plot packages). |
