# Git command cheat sheet

&nbsp;&nbsp;&nbsp;The tutorials in this handbook focus primarily on using Git through the graphical interfaces available in GitHub, RStudio, and VS Code, so **you likely won't need to use Git commands directly** for most everyday tasks. However, Git can also be used through the command line (terminal), which can be useful for more advanced operations, troubleshooting, or simply for those who prefer working this way.

&nbsp;&nbsp;&nbsp;The [Atlassian cheat sheet](https://www.atlassian.com/git/tutorials/atlassian-git-cheatsheet) provides a quick reference for commonly used Git commands and their purposes. **Learning these commands is entirely optional** and is not required to complete any of the tutorials in this handbook.
