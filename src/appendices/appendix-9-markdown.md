# Building and editing Markdown files
&nbsp;&nbsp;&nbsp;Markdown is a simple way to format your text using basic symbols. Markdown files have the extension `.md` and are commonly used on GitHub to create `README.md` files, which we've briefly mentioned in previous tutorials. Some projects may have other Markdown files in addition to your `README.md`, such as files containing SOPs, instructions, protocols, and other written resources.

### 1. Understanding Markdown syntax
&nbsp;&nbsp;&nbsp;Markdown uses basic symbols to format text. Here are some of the most common examples:

| Formatting | Symbols to use |
|---|---|
| Main heading |  `# main heading` |
| Subheading | `## subheading` (keep adding `#` for lower heading levels) |
| Bold text | `**bold text**` |
| Italic text | `*italic text*` |
| Bullet point | `- list item` or `* list item` |
| Numbered list | `1. first item` | 
| Link | `[link text](https://example.com)` |
| Image | `![image description](image.png)` |

&nbsp;&nbsp;&nbsp;For more formatting options, including tables, checklists, code blocks, see this online [Markdown cheat sheet](https://www.markdownguide.org/cheat-sheet/).

### 2. Create and edit Markdown files on GitHub
&nbsp;&nbsp;&nbsp;You can create and edit Markdown files directly on the GitHub website, just like any other file. To learn how to create and edit files on the GitHub website, please refer to [Level 1 - Tutorial 3 - Editing and Uploading Files Through GitHub](../github-learning-resources/level1/tutorial-3.md).

### 3. Optional - Editing Markdown Files in VS Code

&nbsp;&nbsp;&nbsp;If you prefer working on Markdown documents locally, Visual Studio Code (VS Code) provides a convenient way to write, edit, and preview Markdown files without using external tools.

&nbsp;&nbsp;&nbsp;The [Markdown All in One](https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one) extension is particularly useful for working with longer documents. For example, it allows you to automatically generate and maintain a **Table of Contents (TOC)** based on your document's headings.

To insert a Table of Contents:

1. Install the ***Markdown All in One*** extension in VS Code.
2. Open your Markdown file and position your cursor where you'd like the TOC to appear.
3. Press `Ctrl + Shift + P` to open the Command Palette.
4. Search for ***Markdown All in One: Create Table of Contents*** and select it.
5. The TOC will be inserted at your cursor position and will automatically update when you save the document.

You can also press `Ctrl + Shift + V` to preview how your Markdown document will appear when rendered. This preview feature is built into VS Code and does not require an extension.

*If you're editing a Markdown file from a GitHub repository locally, remember to commit and push your changes to GitHub when you're finished.*
