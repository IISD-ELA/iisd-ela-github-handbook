# Using GitHub Desktop
&nbsp;&nbsp;&nbsp;[GitHub Desktop](https://github.com/apps/desktop) is an app that allows you to manage Git repositories through a simple graphical interface, without needing to use the command line. As mentioned before, if you are already comfortable with using VS Code or RStudio, there's little reason to switch to GitHub Desktop. However, GitHub Desktop might be a better option for true beginners.

### 1. Why use GitHub Desktop?
&nbsp;&nbsp;&nbsp;Unlike RStudio and VS Code, GitHub desktop is not a code editor. Instead, it focuses specifically on Git operations (i.e., pull, pull, commit, clone). You can use GitHub Desktop alongside RStudio, VS Code, or another preferred editor. For example, you can write and run your R scripts in RStudio, then switch to GitHub Desktop to commit and push your changes.

### 2. Getting started with GitHub Desktop
&nbsp;&nbsp;&nbsp;To start using GitHub Desktop:
1. Download and install it from [desktop.github.com](https://github.com/apps/desktop).
2. Once installed, open the GitHub Desktop app and log in using your GitHub account.
3. Configure your Git name and email if prompted.
4. Clone an existing repository from the IISD-ELA GitHub to your computer and begin working with it.

&nbsp;&nbsp;&nbsp;For additional installation and setup instructions, see [Getting started with GitHub Desktop](https://docs.github.com/en/desktop/overview/getting-started-with-github-desktop).

### 3. Simple GitHub Desktop workflow
&nbsp;&nbsp;&nbsp;Once you've cloned your repository, your typical workflow will look something like this:
1. ***Pull*** the latest changes from the remote GitHub repository before starting work.
2. ***Edit your files*** using RStudio or VS Code, or whatever tool you prefer.
3. ***Review your changes*** on GitHub Desktop.
4. ***Commit*** your changes with a descriptive message.
5. ***Push*** your commits to the remote GitHub repository.

&nbsp;&nbsp;&nbsp;This is the same Git workflow we covered in [Level 2](../github-learning-resources/level-2.md), just performed through a different interface. For a more detailed introduction, see GitHub's [Creating your first repository using GitHub Desktop](https://docs.github.com/en/desktop/overview/creating-your-first-repository-using-github-desktop) tutorial.
