# 3. Teams

&nbsp;&nbsp;&nbsp;Teams are used to organize people according to which repositories they need or want access to.

**IISD-ELA GitHub Teams**

| Team Name | Purpose |
|-----------|----------|
| `Adaptive Monitoring` | Adaptive Monitoring Project on Winnipeg River (w/ Aquatic Life) |
| `DB Admin` | A team for managing data infrastructure and back-end data work |
| `ELA Staff` | Scientists and technicians at IISD-ELA |
| `StratoEarth` | A team for StratoEarth consultants |

#### Subteams under `ELA Staff`
- `Chemistry` — ChemLab members
- `Toxicology` — Toxicology-related researchers
- `Plankton` — Zooplankton and phytoplankton related researchers.
- `Fish` — Fish-related researchers.
- `Hydrolim` — Hydrology, limnology, and meteorology related researchers.
- `Water Program` — Water program researchers and staff.
- `Plastics` — Microplastics related researchers and staff.
- `In situ Monitoring` — In situ monitoring researchers and technicians.
